# API REST avec Go et Gin

Une API REST simple et élégante construite avec Go et le framework Gin.

## 🚀 Fonctionnalités

- Architecture en couches (handlers, services, repositories)
- CRUD pour les articles
- Middleware de logging
- Validation des données
- Gestion des erreurs

## 📋 Prérequis

- Go 1.20 ou supérieur
- Git

## 🛠 Installation

1. Clonez le repository
